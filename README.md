# منظومة تتبع المستخلصات — Invoice Tracking

منظومة لمتابعة مستخلصات الشركات المنفذة لمشروعات المصرية للاتصالات، من التقديم لحد الصرف:

- الشركة بتقدّم المستخلص: بنود من Excel (السعر من العقد)، مهمات، مرفقات.
- المستخلص بيمشي في مسار حسب فئة التجاوز C1–C5: مشرف التنفيذ ← مدير التنفيذ ← المدير العام ← الشئون الفنية ← (التخطيط / رئاسة القطاعات / اللجنة العليا) ← رئيس القطاع ← المخازن ← المالية.
- أي محطة تقدر ترجّع المستخلص لأي محطة قبلها بسبب واضح. الـ SLA بيتحسب بأيام العمل، ومع كل حركة إيميل وإشعار.
- كل مستخدم بيشوف نطاقه بس: الشركة، رئاسة القطاعات، القطاع، الإدارة العامة، الإدارة المختصة، السنترال.

## المحتوى

| المسار | الوصف |
|---|---|
| `ديمو/` | المرحلة 0 — ديمو تفاعلي HTML/JS (افتح `ديمو/index.html` من سيرفر محلي). التفاصيل في `ديمو/README.md` |
| `templates/` | قوالب Excel الموحدة لكل البيانات اللي بتدخل المنظومة (12 قالب) |
| `scripts/` | أدوات البيانات: بناء القوالب، استخراج البيانات من ملفات الشركة، ملء القوالب، فحص الاستيراد، اختبار الديمو |
| `docs/data-dictionary.md` | قاموس البيانات وترتيب الاستيراد |
| `erd_*.html` | مخططات العلاقات بين الجداول |

## تشغيل الديمو

```bash
python -m http.server 8765 --directory ديمو
```

بعدها افتح http://localhost:8765 واختار أي مستخدم (شركة، مشرف، مدير تنفيذ، PMO…).

اختبار سريع لكل الشاشات بكل المستخدمين:

```bash
node scripts/demo_smoke.js
```
