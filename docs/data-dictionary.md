# قاموس البيانات — منظومة تتبع المستخلصات

المرجع لفريق الـ IT ولأي حد هيجهز بيانات للاستيراد. قاعدة البيانات PostgreSQL من خلال Prisma.
أسماء الجداول والأعمدة بالإنجليزي (snake_case). الوصف بالعربي.

**قواعد عامة لكل الجداول**
- كل جدول فيه `id uuid PK` و`created_at` و`updated_at`. مش هنكررهم تحت.
- البيانات الأساسية ليها **كود عمل** فريد (`code`). القوالب بتربط ببعضها بالكود مش بالـ id، والـ importer هو اللي بيحوّل الكود لـ FK.
- المبالغ `decimal(18,2)`، والكميات `decimal(18,4)`، والنسب `decimal(5,2)`.
- الأسعار مش بتتاخد من الشركة خالص. السعر بيتجاب من `contract_items.unit_price`، والإجمالي بيتحسب على السيرفر.
- "إلزامي" في الجداول تحت معناها `NOT NULL`. ولو العمود جاي من قالب، فهو عليه `*` في القالب.

**أدوات التجهيز** (كلها `python -I`):

| السكريبت | وظيفته |
|---|---|
| `scripts/build_templates.py templates` | بيبني القوالب الرسمية الفاضية `templates/01..12_*.xlsx` |
| `scripts/extract_example_data.py "Example Data" data-import` | بيحوّل ملفات بريدج الحقيقية لملفات CSV في `data-import/` |
| `scripts/fill_templates_from_example.py templates data-import` | بيملى نسخ من القوالب الرسمية من الـ CSV، والناتج في `data-import/filled-templates/` |
| `scripts/validate_import.py` | بيقرا القوالب المملوءة بنفس طريقة المنظومة، ويكتب `data-import/validation_report.md` |

> **تنبيه:** `Example Data/` و`data-import/` فيهم بيانات حقيقية، وهما في `.gitignore`. ممنوع يترفعوا على GitHub.

## 2. الهيكل التنظيمي (القالب 01، Admin)

| الجدول | الغرض | الأعمدة (غير id) | المفاتيح والعلاقات |
|---|---|---|---|
| `presidencies` | رئاسة القطاعات | `code` string إلزامي، `name` string إلزامي | UK(code) |
| `sectors` | القطاع | `code` إلزامي، `presidency_id` FK إلزامي، `name` إلزامي | UK(code)، presidencies 1←n |
| `general_depts` | الإدارة العامة | `code`، `sector_id` FK، `name` (كلهم إلزامي)، `gm_user_id` FK اختياري (من `gm_email`) | UK(code) |
| `tech_units` | الشئون الفنية (وحدة لكل قطاع) | `code`، `sector_id` FK، `name` | UK(code) |

| `centrals` | السنترال | `code`، `dept_id` FK، `name` | UK(code) |

- **من القالب:** كل شيت = جدول. وعمود `*_code` بيتحول لـ FK.
- **من البيانات الحقيقية:** **مش موجود.** ملفات الموقف فيها بس نص حر في عمود "المنطقة" (زي: المنطقة الشرقية) وعمود "النطاق" (زي: شمال سيناء). والنصوص دي اتنقلت لعمود `notes` في المستخلصات المرحّلة.

## 6. العقود والمقايسة (القالب 05، الشئون الفنية)

| العمود | النوع | إلزامي | الوصف |
|---|---|---|---|

| `vat_pct` | decimal | نعم | 14 |

### `contract_items` (شيت "المقايسة")

| العمود | النوع | إلزامي | الوصف |
|---|---|---|---|
| `contract_id` | FK | نعم | |
| `item_no` | string | نعم | متدرج بالشرطة، زي `1-1-1-2`. والنقطة بتتحول لشرطة |
| `parent_item_no` | string | لا | بيتحسب: كل اللي قبل آخر شرطة |
| `level` | int | نعم | بيتحسب: عدد الأجزاء |
| `is_group` | bool | نعم | الصف اللي **من غير وحدة** = عنوان، وماينفعش يتفوتر عليه |
| `description` | text | نعم | |
| `unit` | string | لا | |
| `contract_qty` | decimal | لا | كمية العقد |
| `unit_price` | decimal **nullable** | لا | فاضي أو صفر = مالوش سعر، وأي فوترة عليه تبقى **C5** |
| `work_type` | enum | لا | أعمال مدنية / تركيبات / كهربية / توريد / توريد وتركيب / تخطيط ورسومات / خدمات / صيانة / صواعد داخل المباني / رفع كفاءة |
| `section` | string | لا | اسم الباب الرئيسي (للتقارير) |

- **المفاتيح:** UK(`contract_id`, `item_no`).
- **من البيانات الحقيقية:**
  - **231/2026/1/12** من `مقايسة بريدج عقد 26.xlsx`، والأعمدة: مسلسل ← item_no، البيان ← description، الوحدة ← unit، الكمية ← contract_qty، سعر الوحدة ← unit_price. فيه 362 صف (294 بند).
  - **232/2025/1/36** من `PO25 بريدج.xlsx`، وده نفس قالب المقايسة بالأسعار. الكمية اللي فيه هي كمية أمر التكليف PO25 **مش كمية العقد**، فـ `contract_qty` فاضي. فيه 469 صف (385 بند، منهم 98 من غير سعر). المقايسة المعتمدة نفسها موجودة PDF بس (`مقايسة أكتوبر معتمدة.pdf`)، فلازم الأسعار تتراجع عليها.
  - **`work_type`** بيتحدد من الباب الرئيسي: 1 أعمال مدنية، 2 تركيبات، 3 تخطيط ورسومات، 4 صواعد داخل المباني، 5 رفع كفاءة، 6 "أعمال إعادة الشيء لأصله" = صيانة (الملف الأصلي بيجمّعها تحت "اجمالي اعمال الصيانة").
  - **مشاكل اتصلحت في الاستخراج:**
    - Excel كان محوّل كودين لتواريخ (37381 ← `5-5-2` و45813 ← `5-6`).
    - كود المهمات 2.10 كان بيتقري 2.1.

| الجدول | الأعمدة | المفاتيح والملاحظات |
|---|---|---|

- **من البيانات الحقيقية:**
  - **PO25 (R0)** من عمود الكمية في `PO25 بريدج.xlsx`، وفيه 32 بند.
  - **PO26 (R0)** من `PO26 قائمة أعمال أكتوبر2 - بريدج.xlsx`، وفيه 32 بند.
  - **PO25 ملحق 1 (R1)** من `PO25 بعد الزيادة قائمة اعمال بريدج .xlsx`. أعمدة `#75 … #127` = مواقع (21 موقع، منهم 20 عليهم كميات، والإجمالي 165 سطر). أعمدة "الكمية (الإجمالى) / سعر الوحدة / الإجمالي" اللي بعدهم **مش مواقع**، وبيتجاهلوا (كانت دي مشكلة في الاستخراج واتصلحت).
  - باقي أوامر التكليف (PO01…PO30 على العقدين) موجودة PDF بس، يعني لازم إدخال يدوي في القالب 06.
  - المهمات المخططة لكل أمر تكليف مش موجودة في أي ملف Excel.
